# 视频管理与按顺序学习升级

本次更新包括视频列表顶部批量操作栏、最多 200 个视频选择、批量移动分类、复制资源引用、改分类、删除，以及名称和修改时间排序。播放器配置增加按顺序学习开关。

## 更新已有群晖项目

1. 在 Container Manager 的映像页，导入 playedu-teaching-api-controls-v1.tar.gz 和 playedu-teaching-web-controls-v1.tar.gz。导入后确认两项镜像均有 controls-v1 标签。
2. 备份原 playedu-teaching 项目的 YAML，并在项目停止后备份数据库。
3. 在原项目 YAML 中，只将 API 镜像值改为 playedu-teaching-api:controls-v1，将 web 镜像值改为 playedu-teaching-web:controls-v1，然后保存、构建并启动。
4. 原项目中已经配置的 HTTPS 9900、端口、目录挂载、证书和自动续期设置继续使用原值。若已部署外网管理入口，更新时请使用第 3 步的两行镜像替换方式。
5. 刷新管理后台。网页使用 Ctrl+F5，安卓 App 重新打开。

## 批量操作

进入资源管理的视频列表，点击批量操作并勾选视频。顶部显示已选数量和四个批量按钮，每次最多 200 个，翻页会保留选择。

批量移动设定一个目标分类，批量改分类可选择多个分类。两者都保留原资源编号及课程学习记录。清空目标分类代表未分类。

批量复制在目标分类建立新的资源引用，名称增加“（副本）”。视频内容继续共用原文件。删除仍被课程使用的视频会被拦截，需要先调整课程引用。NAS 原文件按只读方式使用。

## 排序

NAS 视频库按文件名称或文件自身修改时间排序。资源列表按名称或资源修改时间排序，两者都有升序和降序选项。

资源修改时间记录网站中的资源编辑与分类变更。升级前的历史资源使用添加时间初始化，因为此前系统未记录资源修改时间。

## 按顺序学习

进入系统设置中的系统配置，在播放器配置里打开“按顺序学习”并保存。默认关闭，开启后对所有课程生效。顺序采用课程的章节和课时排序，前面的未完成课时会锁定后续课时，已完成课时可复习。

完成条件采用系统现有“已完成”记录。需要限制跳播时，同时启用“禁止拖动进度条”。此开关控制课时解锁，不提供基于实际观看时长的防作弊审核。

## 验收

先用测试视频检查 200 个选择、批量改分类、复制后分别删除，以及名称和修改时间排序。再用包含两节视频的测试课程，确认按顺序学习开启时第二节锁定，完成第一节后解锁，关闭开关后第二节可以直接学习。

## 回退

停止原项目，把 API 和 web 的镜像标签恢复成升级前的值，构建并启动。新增资源修改时间字段可保留。回退后旧版本暂不执行按顺序学习限制。

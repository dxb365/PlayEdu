# 安卓平板课堂

独立安装、独立桌面图标与窗口的安卓客户端，课程界面使用本项目的移动网页，账号、视频、学习位置和完成状态共用群晖后台。不会启动外部浏览器来上课。需要联网，未实现离线下载。

默认名称：5927课堂。包名：fun.learning5927.classroom。最低 Android 8.0（API 26），目标 Android 15。未依赖 Google Play 服务，没有 ARM/x86 原生库区分。

## 安装与连接

1. 将已签名的 APK 复制到平板，在文件管理器中点开安装。如果系统要求，按提示为当前文件管理器允许“安装未知应用”。小课屏的家长模式或学校管理策略可能需要管理员允许安装；不要刷机或绕过管理。
2. 打开“5927课堂”，默认连接 https://www.5927.fun:8443/ 。这是教学端口，5001 是群晖管理入口。
3. 群晖服务、域名证书及 8443/9443 端口必须先配置完成；目前 GitHub 代码准备完成不等于服务器已上线。App 内“设置 → 课堂地址”可以修改 HTTPS 地址，不能填写群晖账号。
4. 使用教学系统的学习账号登录。重新冷启动时由后台的“自动恢复上次学习”设置决定是否回到上次课时；点击播放继续。切到后台、退出或刷新前暂停并尝试保存，联网期间同时每约 3 秒保存。强行断电/断网仍可能丢失最后几秒未同步的进度。
5. 视频全屏后返回键先退出全屏，之后才返回上一页或确认退出。横竖屏切换保留当前页面。拖动和倍速规则仍以教学后台设置为准。

请在“设置 → 关于设备/关于平板 → Android 版本”确认系统版本。购买时间不能确定系统版本。京东方小课屏 A1S 的具体固件、WebView 版本和安装权限需要实机确认；本项目没有声称已在该型号上测试。若界面空白，请先通过设备官方更新渠道检查 Android System WebView 或系统更新。

## 构建与签名

使用 JDK 17、Gradle 8.13、Android SDK platform 35 / build-tools 35.0.0：

    gradle -p playedu-android testDebugUnitTest lintDebug assembleDebug assembleRelease

GitHub Actions 的 android-pad 工作流生成体验版（preview.apk）和未签名正式版（unsigned.apk），同时执行单元测试、学习进度逻辑测试、Android 平板模拟器测试。体验版可直接安装，但 CI 的调试签名每次可能变化，因此后续体验版可能需要卸载重装。正式使用请使用同一私人签名证书签名正式版，并增加 versionCode 后更新。

正式版未签名 APK 已 zipalign。可在本地用 Android SDK 的 apksigner 和本人保管的 keystore 签名；不要把 keystore、密码、服务器私钥提交仓库。签名文件应单独离线备份，后续升级必须使用同一密钥。客户端代码、图标和打包配置保存在本目录，版权及上游界面标识予以保留。

## 验证范围

单元测试核对 HTTPS 地址、端口、登录信息与外部导航边界。前端测试验证真实进度模块在 App 后台事件中保存当前位置并暂停，保持已完成进度；模拟器测试核对原生后台事件、会话存储和全屏返回。未替代 A1S 实机的视频解码、触控和实际群晖网络测试。
